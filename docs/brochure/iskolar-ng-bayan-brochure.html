How the AI works

Rules first.
Then the model.

01

Eligibility rules

Fixed policy, not machine learning. All five must pass:

Exam ≥ 80%Average above 75Not 4PsNot SPESNo other scholar in family

Fails one? Not scored. Staff see which rule failed.

02

Random Forest scores the chance

300 decision trees estimate the chance of qualifying from 9 inputs: academic average (merit), plus income, MSWDO poverty flag, household size, dependents, children, seniors, PWDs, and solo parent (need).

03

Explanation

Shows how much each input raised or lowered that applicant’s chance.

04

Priority ranking

Ranked within the same program and year, so staff review the strongest cases first.

System overview

What Is
Iskolar ng Bayan?

Iskolar ng Bayan is an AI-assisted scholarship applicant screening and management system designed to help the Local Youth Development Office of Santa Cruz, Laguna organize applicant records, manage scholarship applications, review screening recommendations, and document official decisions.

Simple workflow

From Application
to Decision.

01

Register

Create applicant profiles and record scholarship applications.

02

Screen

Eligibility rules run first. The AI then scores each eligible applicant and explains the score.

03

Review

Staff work down the ranked list, correct inputs if needed, and coordinate interviews.

04

Decide

An authorized official records the final decision with written remarks. Every action is logged.

People Decide.
